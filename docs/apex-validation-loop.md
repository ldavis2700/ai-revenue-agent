# APEX Validation Loop

APEX now uses a measured, safety-gated loop for business-model selection and validation.

1. Rank the eligible business-model universe using risk-adjusted heuristics.
2. Blend fresh measured economics into pursuit scores.
3. Compare a measured champion against the strongest credible challenger.
4. Maintain one active bounded validation experiment per model.
5. Default automatically created validation experiments to a zero-dollar cost cap.
6. Stop experiments when declared cost or sample caps are reached.
7. Promote models only from measured evidence; stale evidence decays over time.
8. Keep outbound sends, spending, contracts, charging, customer-system changes, and irreversible production changes behind separate authorization gates.

This loop is designed to improve decision quality and capital discipline. It does not guarantee revenue or profit.
